# HAIRSPRING paper

`hairspring.tex` is the editable manuscript. `make all` renders `hairspring.pdf` with pdfLaTeX. `make_figures.py` regenerates the figures. `reproduce.py` recomputes source and benchmark totals from the checked-in raw evidence.

The manuscript describes commit `4273dccf6d00fa727b01fcbdedc6773ace9eca12`. Its raw benchmark files are immutable records copied from the matched HAIRSPRING and SWE-agent run directories on the evaluation host.
