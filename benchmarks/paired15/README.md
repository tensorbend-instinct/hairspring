Both harnesses use the DeepSeek Flash model through the same admission-metered proxy and no external network access inside their separate bubblewrap workspaces. One compute instance, one run at a time. The proxy keeps a $150 external ceiling but does not impose mission step or wall-time caps. The HAIRSPRING and critic mission step/wall/spend caps are opt-in (including delegated child missions); the OpenHands loop likewise has no added mission cap. HAIRSPRING author, critic, and the metering proxy no longer impose per-call model kill timers: a call waits for provider completion or actual transport failure. The proxy keeps the mission-wide $150 admission ledger, reserves conservatively before each call, settles provider usage when available, and books the full reserve when usage is unknown. Stalled calls therefore keep their reserve and need an explicit operational stop and reconciliation rather than a synthetic deadline. HTTP framing and pooling are handled by pinned httpx; the pinned httpx-sse decoder recognizes SSE terminal events and usage while the proxy forwards provider request and stream bytes without JSON reserialization. A still-reserved ledger halts the sequential batch until settlement or manual audit. The runner never native-grades a nonterminal/error run. DeepSeek currently requires `max_tokens` to be at most 393216; both adapters request this provider maximum, not a lower experimental output cap (https://api-docs.deepseek.com/api/create-chat-completion and https://api-docs.deepseek.com/quick_start/pricing, checked 2026-09-27). Omitting it would use DeepSeek's lower 8K/64K defaults. A task is correctly solved only with terminal run evidence plus native grade. OpenHands steps count distinct LLM response IDs from agent ActionEvent and MessageEvent, so a response with no tool action still counts as a step; parallel actions in one response count once. Its FINISHED status with zero AgentErrorEvent/ConversationErrorEvent gates native grading; ERROR, STUCK, and error-bearing FINISHED runs remain unfinished. All records, traces, patches, grades, and accounting should be preserved. Do not report cost in the comparison table; use solved, steps, and wall time. This experiment is exploratory and cannot support a state-of-the-art claim from 15 instances.
